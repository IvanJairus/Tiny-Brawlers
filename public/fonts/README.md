# Letters

Two latin-subset woff2 files, self-hosted so the game never makes a third-party
request and still renders correctly offline:

- `baloo2-latin.woff2` with `baloo2-OFL.txt`
- `nunito-sans-latin.woff2` with `nunito-sans-OFL.txt`

Both families are licensed under the SIL Open Font License 1.1; the license files
are the copies shipped by the upstream projects and each carries its own copyright
and Reserved Font Name notice. Do not remove those files when copying the fonts.

The subsets were fetched from the Google Fonts static CDN on 2026-10-15 (Baloo 2
v23, Nunito Sans v19). They cover the latin ranges Google publishes, which is all
the game's Indonesian and English strings need.
